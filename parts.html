配件更换与机油价格

保养花多少钱，取决于你买什么规格、在哪买、在哪装。本页把机油、滤芯、火花塞、刹车、变速箱油的价格与规格 排成可对比的表格，方便你判断 4S 报价是否合理。

关于价格：下表价格为市场参考区间，随渠道（4S / 途虎 / 京东自营 / 天猫旗舰店 / 汽配城）、 地区、品牌与促销波动明显，通常有 ±30% 的浮动。用途是判断量级与比价，不是报价单。

一、机油价格对比Oil

选机油先看认证（MB 229.x），再看粘度，最后才看品牌。同一认证下的不同品牌价格可以差一倍以上。

怎么算一次保养用几升

奔驰四缸涡轮机的机油容量大多在 5.5～6.5 L，六缸机 6.5～8 L。 常见做法是买一桶 4L + 一桶 1L，或直接买 5L 装再补一桶 1L。

省钱提示：电商大促（618、双 11）时的 4L 装全合成常有 5～6 折， 一次囤两三次保养的量是最划算的做法。机油保质期通常 4～5 年，未开封常温存放没问题。

二、滤芯类Filters

滤芯是典型的「原厂件 = 大牌代工」品类。曼牌（Mann）、马勒（Mahle）、博世、汉格斯特是奔驰最常见的代工方， 价格往往只有 4S 的一半甚至三分之一，品质一致。

三、火花塞Spark Plugs

涡轮增压直喷发动机的火花塞更换周期比自然吸气短得多。用错型号会导致失火、抖动甚至损坏点火线圈。

选购要点：必须按发动机代号选型号，热值与间隙不能随意替换。 奔驰原厂火花塞多由 NGK 或博世代工，直接买对应型号的 NGK/博世产品是同质低价的选择。 更换时建议四支同批，不要混用不同品牌或新旧混装。

四、刹车片与刹车盘Brakes

刹车是安全件，这里的钱不该省。但「4S 换刹车片 4000 元」和「靠谱修理厂换同品质 ATE 件 1500 元」之间， 差别主要来自渠道加价而非零件本身。

什么时候该换

  • 刹车片摩擦材料厚度小于 3 mm必须换（新片约 10～12 mm）。
  • 仪表出现刹车片磨损报警（多数车型有传感器）。
  • 刹车盘厚度低于最小允许值（盘面有刻印 min 值）、或出现明显沟槽、翘曲抖动。
  • 刹车时有尖锐金属摩擦声、或制动距离明显变长。
  • 换盘必须同换片；换片时若盘有台阶或偏磨，也应一并处理。

五、变速箱油ATF

奔驰不同代变速箱使用的油品认证完全不同，加错油会直接导致换挡冲击甚至变速箱损坏。

红线提醒：奔驰变速箱油的认证互不通用，而且 722.9 本身还要分两个阶段：
  • 722.6（5G-TRONIC）→ MB 236.10（236.12 / 236.14 亦可）
  • 722.9（7G-TRONIC，2010-06 之前）→ MB 236.14
  • 722.9（7G-TRONIC PLUS，2010-06 起）→ MB 236.15
  • 725.0（9G-TRONIC）→ MB 236.17

「722.9 一律用 236.15」是最常见的错误说法。加油前务必核对变速箱型号与油品认证号， 不要听信「都是奔驰 ATF 通用」。更换方式分重力换油（约 5～7 L）与循环机换油（约 10～12 L）两种， 老车里程高且从未换过油的，建议先做重力换油，风险更低。

六、刹车油Brake Fluid

成本最低、最容易被拖延、后果最直接的一项。刹车油会持续吸收空气中的水分， 含水量上升会让沸点大幅下降——连续下坡或激烈驾驶时，沸腾产生的气泡会让刹车踏板直接踩空。

更换要点：周期为 2 年（或 4 万公里）。必须用压力排气机更换， 靠脚踩排气很难把 ABS 泵与管路里的旧油彻底换净。奔驰车型需要 DOT4 及以上， 带 ESP/ABS 的车型建议使用 DOT4 Plus（原厂 Blatt 331.0 规格）。 不要把 DOT5（硅油基）混进 DOT4 系统，两者不兼容。

七、工时费与保养总价参考Labour

同样的项目，4S 店与综合修理厂的价格差可以达到 2～3 倍。保修期内的新车建议留在 4S， 出保后找一家熟悉奔驰的专修店是主流选择。

可以自己动手

空调滤芯、空气滤芯、雨刮片、蓄电池（部分车型需注册）、灯泡。 这几项在 4S 的工时费往往是零件本身的数倍，自己换能省一大半。

必须交给专业

变速箱油（需要专用设备与油温校准）、刹车油（需要压力排气与诊断仪）、 正时链条、空气悬挂、任何涉及高压系统的项目。

影响残值

完整的保养记录（最好有 4S 或专修店的盖章工单）在二手交易时值几千元。 从小修理厂换到路边摊省下的钱，往往在卖车时加倍还回去。

八、配件选购的六条原则Rules

1. 安全件不省

刹车（片/盘/油）、轮胎、轮毂、转向与悬挂件。这些是唯一直接决定生死的部分。

2. 认证优先于品牌

机油看 MB 229.x，变速箱油看 MB 236.x，刹车油看 DOT4 Plus。有认证的杂牌， 好过没认证的大牌。

3. 认准零件号

奔驰原厂零件号形如 A2711800009。 用它去查代工件是最可靠的方式，能避免买错型号。

4. 渠道比价格重要

机油、刹车片、火花塞是假货重灾区。优先京东自营、天猫官方旗舰店、品牌授权经销商， 不要买「比市场价便宜 40%」的同款。

5. 成对/成套更换

刹车片同轴成对换、火花塞四支同批、减震器同轴成对换。 单侧更换会导致左右制动力或阻尼不一致。

6. 留好工单

每次保养保留工单与零件发票，既方便追踪下次保养时间， 也是卖车时最有力的车况证明。
