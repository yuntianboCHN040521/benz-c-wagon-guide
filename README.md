# 奔驰 C 级旅行车数据库（S203 / S204 / S205 / S206）

![预览](preview.png)

一个纯静态网站，整理 **2000 年以后奔驰 C 级旅行车（Estate / T-Modell）** 的用车指南、
车身数据、轮毂数据、改装适配计算、配件更换与机油价格。

无框架、无构建、无依赖——双击 `index.html` 就能用，也可以扔到任何静态托管上。

## 快速开始

**方式一：直接打开**

双击 `index.html`。

## 核心：改装计算器做了什么

计算不是拍脑袋的估计，而是有明确公式的几何推算。坐标约定：以**轮毂安装面**为原点，
x 轴指向车身外侧为正；ET 为正值时轮辋中心线位于安装面内侧（x = −ET）。

| 计算项 | 公式 |
|---|---|
| 轮胎外径 | `轮辋直径 × 25.4 + 2 × (胎宽 × 扁平比 / 100)` |
| 轮辋外缘位置 | `辋宽 / 2 × 25.4 − ET` |
| 轮辋内缘位置 | `−(辋宽 / 2 × 25.4 + ET)` |
| 背距 / 前距 | `辋宽/2×25.4 + ET` / `辋宽/2×25.4 − ET` |
| 胎壁外缘位置 | `胎宽 / 2 − ET` |
| 单轴轮距变化 | `胎壁外移量 × 2` |
| 离地间隙变化 | `(新外径 − 原外径) / 2` |
| 码表真实车速 | `仪表车速 × (新外径 / 原外径)` |

评级规则（三条硬性红线）：

1. 轮胎外径偏差 **不超过 ±3%**（±2% 内为理想）
2. 胎壁外移量 **不超过 12 mm**（≤6 mm 为齐边）
3. 载重指数 **不低于** 按轴荷核算的需求值（轴荷 ÷ 2 × 1.1）

评级取**前后轮中较差的一侧**——后轮的风险不会被前轮的绿灯掩盖。

### 轮毂尺寸可用性矩阵

`fitment.html` 里的矩阵把「辋宽 × ET」的常见组合穷举算完，每个单元格给出
**胎壁相对原厂的外移量**，按安全 / 需实测 / 不建议三档着色。
它回答的是选型时的第一个问题：*这个宽度的轮毂，ET 该选多少？*

## AI 助手

`assistant.html` 是这个数据库的站内助手。它有**两种模式**，默认的那种开箱即用。

### 模式一：离线检索（默认，不需要 key、不需要联网）

完全跑在浏览器里：把 `CDATA` 的全部数据展平成 **389 条知识条目**，再用
「同义词归一 → 中文 2-gram 分词 → 车型实体识别 → 加权打分」检索，最后按意图套用回答模板。

能处理的问题类型：

| 意图 | 例子 | 回答方式 |
|---|---|---|
| 车身数据 | `S205 的轴距是多少` | 给数值 + 四代对比表 |
| 轮毂参数 | `W204 原厂 17 寸的 ET 是多少` | 给规格 + 实时算出的背距/前距 |
| 通病故障 | `W204 有什么通病` | 列出该代全部通病（现象/原因/对策/参考价） |
| 机油认证 | `W205 用什么机油` | 认证、粘度、容量 + 价格对比 |
| 保养周期 | `机油多久换一次` | 周期表 + 参考价 |
| 价格 | `刹车片多少钱` | 原厂与替代品牌零件号 + 区间 |
| 品牌轮毂 | `BBS 有哪些适配的轮毂` | 型号、工艺、5×112 规格、载荷、价格 |
| 两代对比 | `S204 和 S205 的轴距差多少` | 对比表 + 差值 |
| **实时计算** | `225/50R17 换成 245/40R18`<br>`8.5Jx19 ET45 装 W205 会刮吗` | 现场调用计算引擎，给外径差、胎壁外移、轮距变化、码表误差与综合评级 |
| 灯光操作 | `示宽灯在哪里`<br>`驻车灯怎么开` | 开关位置与档位、单侧驻车灯操作步骤、四代差异 |
| 仪表故障灯 | `机油压力灯亮了怎么办`<br>`红色故障灯有哪些` | 颜色分级、能否继续行驶、可能原因与处理步骤 |
| 车内按键 | `怀挡怎么用`<br>`方向盘上的按键是干什么的` | 按区域列出按键功能 |
| 数据缺口 | `哪些数据没有核实` | 列出全部未核实项 |

还可以用 URL 直接分享某个问题：`assistant.html?q=S205的轴距是多少`。

### 模式二：大模型对话（可选，用自己的 key）

填入 API key 后，助手会把**检索到的站内资料作为上下文**一起发给模型，并在系统提示里
明确要求「只依据资料回答、不得编造数字」。调用失败（key 无效、余额不足、CORS 限制）会
**自动回落到离线模式**，功能不中断。

key 只存在浏览器的 `localStorage` 里——本站是纯静态页面，**没有后端**，
静态页里内置任何 key 都等于公开泄露，所以让每个使用者填自己的 key 是唯一安全的做法。

另外还有一个兜底：点「复制『资料 + 问题』给别人」，会把检索到的资料和你的问题一起复制到剪贴板，
粘贴到任意 AI 对话框即可。

## 灯光、按键与故障灯

`controls.html` 回答三类「车主最常问但说明书里很难翻到」的问题：

**① 示宽灯 / 驻车灯在哪、怎么开**

先用一句话区分：**示宽灯是两侧一起亮的小灯，驻车灯是只亮一侧的小灯**。
重点是「单侧驻车灯」的完整操作步骤，以及四代灯光开关的位置差异。

整理过程中**推翻了一个流传很广的说法**：车主之间常说「熄火后拨转向灯拨杆就能点亮单侧驻车灯」，
但 W203 与 W204 的官方手册原文里都没有这种做法——两代都是**灯光旋钮上的独立档位**
（W204 手册图例：`W = 左侧 standing lamp`、`X = 右侧`、`T = 双侧驻车灯`）。
页面把这个更正单独标了出来。

W203 / W204 已由官方手册核实为仪表台左侧的旋转旋钮；
**W205 / W206 未核实**（奔驰官方在线手册是 JS 渲染页面，只能取到章节标题），
页面如实标注为未核实而不做猜测。

**② 车内按键功能**

按「坐进车里会看到的位置」分区：方向盘、方向盘后方拨杆（含 W205/W206 的怀挡）、
仪表台左侧、中控台、车门、座椅、顶棚。

**③ 仪表故障灯**

覆盖 22 个常见警告灯，每个给出：图标、颜色分级、含义、**能否继续行驶**、
按概率排序的可能原因、车主能自己做的处理步骤、以及奔驰特有的补充说明。

图标全部是**手绘 SVG 几何图形**（`car-icons.js`），不引用任何厂商素材；
按颜色分级自动着色，红/黄/绿/蓝一眼可辨。

页面最后还有「故障灯亮了，通用处理流程 5 步」和「这些情况别犹豫，直接叫拖车」的对照表。

## 数据来源、缺口与免责

### 来源性质

- **车身与轮毂数据**：奔驰官方档案站（mercedes-benz-publicarchive.com 车型页）、
  官方车主手册（W204/W205 的 Rad-Reifen-Kombinationen 轮组表）、官方配件站、
  法国 L'argus 与德国 auto motor und sport 的车型技术表、日本 YANASE 目录、
  auto-data.net 逐车型页，以及 W203 官方维修手册。
- **品牌轮毂**：BBS / OZ / RAYS 官网、JMS Fahrzeugteile、Blackhawk Japan、
  bbswheels.ru、reifen.com、ATS 官方 Gutachten 等实际抓取页面。
- **机油与配件价格**：京东、天猫、途虎、汽车之家、什么值得买的实拍与车主帖，
  以及 Kroon-Oil 的车型保养页。采集时间跨度较大（部分为 2015–2019 年的促销记录），
  均标注了来源与时间。

### 关于「官方手册 vs 流传数据」

整理过程中发现两处流传很广但与官方资料不符的数字，本站以官方资料为准并明确标注：

| 车型 | 流传说法 | 官方资料 |
|---|---|---|
| S205 原厂 17 寸 | 7.5J×17 ET45.5 | **7.0J×17 ET48.5**（W205 车主手册 2014-05 轮组表） |
| S203 原厂 17 寸 | 7.5J×17 ET36 | 官方手册 ET 只有 **31 / 37 / 44** 三档 |

### 已明确标注的数据缺口

本站**不猜测数据**。抓不到可靠来源的字段一律留空并说明原因，这些缺口在
`parts.html#gaps` 与 `fitment.html#brands` 页面底部集中列出，主要包括：

- 各代的最小离地间隙、S204/S205 的风阻系数与部分最大允许总质量
- W203 / W204 / W206 的部分机油容量（W205 汽油机 7.0 L 已由官方手册核实）
- 机油滤芯、刹车盘的人民币零售价（电商页为 JS 渲染，比价站有验证码，配件站返回 403）
- 燃油滤芯（内置式）的原厂零件号与价格
- W206 的官方逐项 ET（官方 PDF 无法解析）
- Enkei 的 5×112 规格（官网规格表为 PDF，在售规格均为 5×114.3）
- 品牌轮毂的螺栓座面（球面/锥面）——除奔驰原厂前提外均无法确认

### 免责

**轮毂轮胎属于行车安全件。** 安装前请务必：

1. 以实车测量轮拱、避震筒、内衬与卡钳间隙（用橡皮泥做动态测试，不要只靠尺子）
2. 核对轮毂厂商标称载荷，不得低于单轮需求
3. 确认螺栓的球面/锥面座面与螺纹长度，**奔驰原厂为球面 R14**
4. 检查 TPMS 传感器兼容性与频率
5. 改装后重做四轮定位
6. 遵守当地关于轮距变更与轮胎规格的法规要求

价格均为参考区间，随地区、渠道与时间波动明显（通常 ±30%），不构成报价。
本站内容仅供选型参考，改装风险自负。

## 如何扩展数据

所有内容集中在两个数据文件中：

- `data/c-class-data.js` —— `window.CDATA`：四代车型（`generations`）、推荐方案（`plans`）、
  MB 机油认证（`mbSpecs`）、发动机用油（`engineOil`）、保养周期（`intervals`）、
  机油（`oils`）、滤芯（`filters`）、火花塞（`sparkPlugs`）、刹车（`brakes`）、
  变速箱油（`transmissionFluids`）、刹车油（`brakeFluid`）、工时费（`labour`）
- `data/wheel-brands.js` —— `window.CDATA.brands` / `amgOem` / `brandNotes` / `brandSources`

新增一个车型代际，往 `generations` 数组里加一个对象；新增推荐方案往 `plans` 添加；
新增品牌往 `brands` 添加。字段结构参照现有条目。

改完跑一次两个自检脚本即可确认没有破坏结构。
