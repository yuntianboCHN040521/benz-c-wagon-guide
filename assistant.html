Assistant

站内 AI 助手

直接问就行。助手会检索本站已核实的数据来回答——车身尺寸、轮毂 ET 与适配、改装能不能装、 通病与维修价、保养周期、机油认证与配件价格，涉及规格的问题还会现场调用计算引擎算出结果。

模型设置可选

默认的离线检索模式不需要任何配置，答案完全来自本站数据。 如果你希望助手用更自然的语言组织回答，可以填入自己的 API key 切换到大模型模式—— 检索到的本站资料会作为上下文一起发送，所以它仍然只依据本站数据回答。

常用配置：DeepSeek https://api.deepseek.com/v1 + deepseek-chat； OpenAI https://api.openai.com/v1 + gpt-4o-mini； OpenRouter https://openrouter.ai/api/v1。

关于 key 与隐私

  • key 只存在你浏览器的 localStorage 里，不会上传到本站——本站是纯静态页面，根本没有后端。
  • 请求由你的浏览器直接发往你填的 API 服务商，本站不经手。
  • 如果服务商不允许浏览器直连（CORS 限制），会提示失败并自动回落到离线检索，功能不受影响。
  • 不想配 key 也可以用右上角的「复制资料 + 问题」，粘贴到任意 AI 对话框里。
为什么不内置 key？静态页面里的任何 key 都会随源码公开，等于泄露。 让每个使用者填自己的 key 是这类站点唯一安全的做法。

开始提问

S205 轴距 W204 通病 W205 用什么机油 BBS 轮毂 换胎计算 刹车片价格 两代对比 数据缺口
回车发送。助手只依据本站已核实的数据回答；站内没有的数据它会直接说没有，而不是编一个。

它能回答什么Capability

结构化查询

  • 「S206 的前轮距」→ 直接给数值，并附四代对比表
  • 「W204 原厂 17 寸的 ET 是多少」→ 给规格 + 背距/前距
  • 「W203 有什么通病」→ 列出现象、原因、对策、参考价
  • 「C63 的发动机参数」→ 功率、扭矩、年份、原厂轮组

实时计算

  • 「225/50R17 换成 245/40R18」→ 外径差、胎壁外移、轮距变化、码表误差
  • 「8.5Jx19 ET45 装 W205 会刮吗」→ 以该代原厂为基准给出评级
  • 没给车型时会默认以 S205 原厂配置为基准并明确说明

价格与耗材

  • 「机油多少钱」→ 品牌、认证、容量、单价对比
  • 「刹车片价格」→ 原厂与替代品牌零件号
  • 「变速箱油怎么选」→ 722.6 / 722.9 / 725.0 的认证区别

灯光与操作

  • 「示宽灯在哪里」→ 开关位置、档位，以及与驻车灯的区别
  • 「驻车灯怎么开」→ 单侧驻车灯的完整操作步骤
  • 「灯光开关在哪」→ 四代差异对比表
  • 「怀挡怎么用」→ 按区域列出车内按键功能

仪表故障灯

  • 「机油压力灯亮了怎么办」→ 含义、能否继续行驶、原因与处理步骤
  • 「红色故障灯有哪些」→ 按颜色筛选
  • 「故障灯颜色分级」→ 红/黄/绿/蓝各自的处置优先级

诚实边界

  • 问「哪些数据没有核实」会列出全部数据缺口
  • 检索不到时会明说「站内没有这项数据」，并给可替代的问法
  • 大模型模式下，系统提示明确要求只依据站内资料回答、不得编造数字
回答的边界：助手读取的是轮毂数据、 车身数据、用车指南、 轮毂适配、配件与机油五个页面的数据源， 与页面内容完全同源。页面上标注为「未核实」的字段，助手也会如实回答未核实。
