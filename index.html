不管你手上是哪一代 C 级旅行车，轮毂安装的这几个数字是共通的——这也是奔驰改装件生态丰富的原因。

一句话总结：2001 年至今所有 C 级旅行车的轮毂安装面都是 5×112、 中心孔 66.6 mm、球面 R14 螺栓，只有螺栓螺纹规格在 W203 → W204 之间从 M12×1.5 升级到 M14×1.5。这意味着轮毂本体通常可以跨代互换，但螺栓不行。

② 再决定要不要动轮毂

改装轮毂的收益与代价都很直接：

  • 得到 视觉姿态、更宽的接地面积、更短的胎壁带来的转向响应、更轻的簧下质量。
  • 付出 舒适性下降、胎噪上升、轮胎与轮毂成本翻倍、容易刮蹭、二手残值受影响。
  • 风险 载重不足、码表失准、轮距超限、ESP 报警、轮胎偏磨、避震与轴承加速磨损。

把这两个配置丢进计算器，它会把上面每一项都算给你看。

数据来源性质。本站数据整理自公开技术资料、厂商技术文档（含奔驰原厂 Technical Accessories 目录与 originalteile.mercedes-benz.de 官方配件站）、轮毂厂商标称参数与车主社区实测反馈。整理过程力求准确， 但车型年款差异、不同市场（欧版 / 中规 / 美规）配置差异、选装包差异都会导致实际数据不同。

价格性质。所有价格均为参考区间，随地区、渠道（4S / 修理厂 / 电商）、品牌与时间波动很大， 仅用于判断量级，不作为报价依据。抓不到可靠来源的字段一律留空——完整清单见 配件与机油 · 数据缺口与轮毂适配 · 品牌数据缺口。

改装风险自负。轮毂轮胎属于行车安全件。安装前请务必： 以实车测量轮拱与避震间隙、核对轮毂厂商标称载荷（不得低于单轮需求）、确认螺栓球面/锥面与长度、 检查胎压监测传感器兼容性，并遵守当地关于轮距变更与轮胎规格的法规要求。
